# Preistafel KI-Coding-Modelle

Gemessen in echten Claude-Code-Sessions (Abo), bewertet mit regionalen API-Preisen

- Preistafel: https://godmodeai2025.github.io/Preistafel/
- `data/runs/`: bereinigte Messergebnisse je Lauf
- `data/prices/`: verwendete Preis-Snapshots
- `skill/`: der Mess-Skill (herdr-bench); versteckte Tests nur als Prüfsumme
- `site/feeds/<kohorte>.json`: maschinenlesbares Preissignal

Einmalig in den Repo-Einstellungen: *Settings → Pages → Source: GitHub Actions*.
